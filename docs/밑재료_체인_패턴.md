# 밑재료 체인 패턴 (3.0~7.0 x.0, 전승록 제외)

## 1. 금속: 광석 → 덩어리 → 주괴
공식: **신규 광석(또는 모래) 4~5개 + 과거 광석 1개 + 크리스탈**
- 3.0~5.0은 신규 ×4 (+크리스탈 3~7), 6.0·7.0은 신규 ×5 (+크리스탈 8).
- 6.0 이후 "덩어리" 단계는 최상위 소수만 남고(6.0: 2개, 7.0: 2개), 나머지는 광석 → 주괴 한 단계.
- 과거 광석 1개가 어디서 오는지:

| 패치 | 과거 광석로 쓰인 것 (괄호=원래 등장 패치) |
|---|---|
| 3.0 | 미스릴·철·은·금·암철 광석 (2.0), 그레네이드의 잿가루 (2.0) — 전부 2.0 |
| 4.0 | 구리·철·은·호박금·경철 광석 (2.0) — 전부 2.0 |
| 5.0 | 구리·금·은 (2.0), 티타늄 광석·미스라이트 광석/모래 (3.0) |
| 6.0 | 은·주석·아연 (2.0), 몰리브덴 광석 (4.0), 디미스라이트 광석 (5.0) |
| 7.0 | 경철 (2.0), 몰리브덴 (4.0), 경금 광석/모래 (5.0), 휘취은 광석/모래 (6.0), 마그네시아 가루 (7.0, 신규) |

- 해석: 3.0~4.0은 2.0 광석만 쓰다가 5.0부터 직전 확장·그 이전 확장 광석이 섞이고, 7.0에서는 직전 확장(효월)·직전전 확장(칠흑) 광석 비중이 커짐 (패턴 기반 추정).
- 같은 과거 광석이 여러 확장에서 재등장: 몰리브덴 광석(4.0) → 6.0 망간, 7.0 오르코 크롬 / 은 광석(2.0) → 4.0, 5.0, 6.0 모두.

## 2. 석재: 원석 ×3 + 숫돌 ×1
- 3.0: 원석 + 2.0 숫돌(달걀·수성암) 또는 3.0 백운모 숫돌
- 4.0: 원석 + 규암(2.0)  / 5.0: 원석 + 새 숫돌(경니암·응회암), 영청 석재만 규암(2.0) 사용
- 6.0: 신규 숫돌만 / 7.0: 원석 + 6.0 철운모 숫돌 (2개), 이후 신규 마그네시아 숫돌
  → 숫돌이 "과거 재료" 슬롯. 7.0은 직전 확장 숫돌을 재활용.

## 3. 가죽: 생가죽 ×3~4 + 명반 ×1
- 5.0 노란 명반 → 6.0 하위 2종이 노란 명반 재사용, 이후 에블라나 명반(6.0) → 7.0 하위 3종이 에블라나 명반 재사용, 이후 신규 부자재(아까시나무 껍질).
  → 규칙: **새 확장 하위 티어는 직전 확장 명반, 상위 티어는 신규 부자재.** (칠흑→효월→황금 3번 연속 확인)

## 4. 목재·옷감: 거의 순수 신규
- 목재는 4.0 이후 전부 원목 ×4~5 한 종류만. 과거 재료 없음.
- 옷감도 4.0 이후 신규 섬유 한 종류만 (6.0·7.0은 1단계). 3.0에만 이슬실·아마실 등 2.0 재료 혼용.

## 5. 연금재: 과거 채집 재료가 가장 많이 재사용됨
- 5.0 환혹수: 고지천연수(5.0) + 4.0 허브(얀샤 미나리 등)
- 6.0 환혹수: 지하 천연수(5.0) + 5.0 허브(뜰냉이·빛거베라·라임바질·긴잎라벤더·참나리) 전부 5.0 것
- 7.0 보석수: 하늘물(6.0) + 5.0 허브(뜰냉이·빛거베라·라임바질·긴잎라벤더·참나리) — 칠흑 허브가 효월·황금까지 2회 연속 재사용
- 마법 잉크: 7.0 텅스텐 마법 잉크에 3.0 무지개목화까지 사용
  → 연금·요리용 허브/물은 오래 가는 재료. 칠흑 허브 5종은 백은에서도 재등장할 가능성 있음(순수 추리 수준, 근거 약함).

## 6. 백은 8.0 대비용 추정 (등급: 패턴 기반 추정, 확정 아님)
- 금속 주괴 레시피 1개당 **과거 광석 1개**가 들어갈 가능성 높음 → 후보: 몰리브덴 광석, 은 광석, 경철 광석, 경금 광석/모래, 휘취은 광석/모래, 마그네시아 가루.
- 가죽 하위 티어는 7.0 부자재(아까시나무 껍질) 또는 직전 명반 재사용 가능성.
- 연금: 5.0 허브 5종 + 6.0/7.0 물 재료 재사용 가능성.
- 목재·옷감은 신규 재료 위주라 사전 준비 불필요.
- 필요한 수량은 레시피당 1개라 소량. 대량 비축보다는 "목록에서 빠뜨리지 않는 것"이 핵심.
