# 백은의 탐구자 채작 추리용 — 확장팩별 레시피 분류 & 칠흑 패턴
출처: ffxiv-teamcraft 데이터(recipes / item-patch / patch-names, 패치 7.57까지). 확장팩 분류 = 결과물이 처음 등장한 패치 기준. (309개는 패치 미상이라 제외)

## 1. 확장팩별 레시피 규모
| 확장 | 레시피 수 | x.0 시점 | 이후 패치 | 전문가(expert) 레시피 |
|---|---|---|---|---|
| ARR | 2750 | 1554 | 1196 | 0 |
| 창천 | 2028 | 834 | 1194 | 0 |
| 홍련 | 1863 | 725 | 1138 | 0 |
| 칠흑 | 2228 | 758 | 1470 | 32 |
| 효월 | 2050 | 806 | 1244 | 72 |
| 황금 | 3244 | 757 | 2487 | 440 |
- x.0 시점 레시피는 확장팩마다 대략 730~830개로 꽤 일정함 → 백은 8.0도 700~850개 선일 가능성(패턴 기반 추정).
- 확장팩 만렙 레시피는 x.0 + x.05에 157(칠흑)/160(효월)/170(황금)개, 나머지는 이후 패치로 분산.

## 2. 칠흑(5.x) 구성
- 패치별: 5.0 758 / 5.05 126 / 5.1 118 / 5.11 110 / 5.2 153 / 5.3 488(최대) / 5.4 153 / 5.5 115 …
- 5.0 레시피 대부분(625개)은 70대 레벨 구간 → 만렙(80) 5.0 레시피는 54개뿐(직업당 4~9개). 만렙 재료 체인은 5.05, 5.2, 5.3, 5.4로 단계적 확장.
- 직업 분포는 BSM 337 / GSM 335 / WVR 313 / LTW 306 / ALC 262 / CRP 231 / ARM 230 / CUL 179 — 요리가 가장 적음.
- 만렙 레시피에서 쓰인 크리스탈: 12종 전부(바람 크리스탈 1099회로 최다).

## 3. 칠흑 만렙 레시피 핵심 재료 (최다 사용)
5.0: 드워프 무명천(96), 유창목 목재(88), 디미스라이트 주괴(85)/덩어리(83), 고목/험산의 에테르 모래
5.05: 텅스텐강 주괴(58), 무지개 결정 석재(56), 칼리코테리움 가죽(38)
5.2: 코발트합금 주괴(55), 메가레니아 가죽(50), 멀바우 목재(43), 자색 구슬(43)
5.3: 천둥의 에테르 모래(87), 취진사(39), 건메탈판(27)
5.4: 백야 결정판(39), 틸라콜레오 가죽(34), 두랄루미늄 주괴(32)
→ 패턴: 확장 중반 패치(.2/.3/.4)마다 "금속·가죽·목재·천" 한 세트가 새 티어로 교체됨. 8.0에서도 8.2~8.4에 새 티어가 올 가능성(패턴 기반 추정).

## 4. 오래 쓰인 재료 (꾸준 패턴)
- 확장을 넘어 4개 이상 확장에서 쓰인 재료: 130종 (persistent_ingredients.csv)
- 예: 곰 기름(창천~황금 5확장, 250회), 장인의 데미마테리아(홍련~황금), 회반죽·화강암·마름돌·바니시·짐승기름 초 등 기초 건축/소모 재료.
- 칠흑에서 나와 효월·황금까지 이어진 재료 119종. 상위: 지하 천연수(효월 48·황금 36, 채집), 텅스텐강 주괴, 디미스라이트 주괴, 바다제비 가죽, 고지대 밀가루, 꼬마레몬(효월 9·황금 12), 노르브란트 박하, 뜰냉이, 크림버섯 등.
- 특징: 이어지는 건 대부분 "채집형 식재료·물·허브"와 "중간 가공품". 장비 재료 금속은 한 확장 이후 거의 안 쓰임.
- 전 확장 재료 사용 비중(크리스탈 제외): 칠흑→이전 확장 재료 약 11%, 효월→칠흑 재료 약 10%, 황금→효월 재료 약 6%. 즉 새 확장 레시피 재료의 90% 안팎은 신규 재료, 직전 확장 재료는 10% 안팎.

## 5. 칠흑 채집 구조 (참고)
- 일반 채집물(70~80): 5.0 시점에 70~80레벨 약 70종, 별 2짜리(히든/고난도) 몇 종(헤마타이트 원석·노란 명반·어둠후추·굵은 초석 등).
- 이후 패치에서 "부흥/발굴대용/개량용/소장용" 같은 이벤트·콘텐츠 전용 채집물이 대량 추가 — 일반 채작 재료와 별개라 분리해서 볼 것.

## 6. 주의
- 확장 판정은 결과물 패치 기준이라 일부 오차 가능. 중간 가공품 비율(칠흑 4.9%, 효월 4.6%, 황금 12.4%)은 분류 방식 특성상 참고용.
