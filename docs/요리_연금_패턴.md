# 요리·연금 패턴 (3.0~7.0 x.0 기준, 전승록 제외)
등급 표기: [확정] 데이터로 확인 / [패턴] 반복 패턴 기반 추정 / [추리] 근거 약한 추리

## A. 요리 (요리사)

### 1. 규모와 구성
| 패치 | 요리·식재료 레시피 | 레벨 구간 |
|---|---|---|
| 3.0 | 29 | 51~60 |
| 4.0 | 36 | 61~70 |
| 5.0 | 36 | 71~80 |
| 6.0 | 37 | 81~90 |
| 7.0 | 37 | 91~100 |
- [확정] 최근 3개 확장은 36~37개로 거의 고정. 레벨마다 2~5개씩 촘촘히 배치.
- [확정] 레벨 구간 마지막 단계(예: 80, 90, 100)에 요리가 몰림 (5.0: 80레벨 4개, 6.0: 90레벨 5개, 7.0: 100레벨 5개).

### 2. 매 확장 신규 "기본 가공 재료" 세트 (채집물 → 1단계 가공, 5개 안팎)
| 패치 | 밀가루 | 기름 | 소금 | 감미료 | 유제품 |
|---|---|---|---|---|---|
| 3.0 | 고원 밀가루 | - | 아발라시아 암염 | 자작나무 시럽 | 발효 버터·사워크림 (야크 젖) |
| 4.0 | 기라바니아 밀가루 | 목화씨 기름 | 해초소금 | 사탕무 설탕 | 두부(대두) / 초원 우유 |
| 5.0 | 고지대 밀가루 | 프란토이오 기름 | 재사용(알라미고·아발라시아) | 정원사탕무 설탕·황금 벌꿀 | 재사용 |
| 6.0 | 검은밀가루 | 사베네어 들기름 | 북해 식염 | 야자설탕 | 갈레안 치즈·사향소 젖 |
| 7.0 | 재사용(고지대·검은밀가루) | 투랄 옥수수유 | 고산 식염 | 로열 메이플 시럽 | 휘핑크림 |
- [확정] "밀가루·기름·소금·감미료·유제품" 5칸 중 3~5칸이 새로 생김. 안 생기는 칸은 직전 확장 것을 재사용(5.0 소금, 7.0 밀가루).
- [패턴] 8.0도 이 5칸 중 대부분이 신규일 것. 어떤 칸이 비는지는 모름.

### 3. 요리 테마 = 그 확장의 지역 음식
| 패치 | 대표 요리 | 모티브 |
|---|---|---|
| 3.0 | 아우플라우프, 양파 그라탱 수프, 양배추말이, 바바루아, 베르미첼리 | 중부·동유럽, 알프스풍 |
| 4.0 | 초밥, 된장국, 탕수육, 바클라바, 셔를럭, 카샤 | 동아시아 + 초원(유목) |
| 5.0 | 파에야, 먹물 스파게티, 코르동 블뢰, 바게트, 에스프레소 콘파냐 | 지중해·프랑스·스페인 |
| 6.0 | 보르슈치, 주레크, 스퀴르, 샥슈카, 렌틸 카레, 카르니야릭 | 동유럽·러시아 + 중동·인도 |
| 7.0 | 타코, 메스칼 소스 요리, 나시고렝, 오므라이스, 아쿠아 파짜 | 중남미 + 일부 세계 요리 |
- [확정] 매번 "그 지역 음식"이 주제. 팬 페스티벌/트레일러의 지역 정보가 나오면 요리 이름 추리 가능.
- [확정] 6.0에 이미 북유럽·동유럽풍(스퀴르=아이슬란드 요거트, 갈레안 치즈, 북해청어, 북해 식염, 보르슈치)이 있음 → 백은이 북유럽 모티브여도 효월과 겹치는 재료(청어·유제품·호밀 계열)는 재사용될 수 있음.

### 4. 북유럽 모티브 후보 (등급: [추리], 신화 모티브 + 일반 북유럽 요리)
출처: Lonely Planet 「What to eat and drink in Scandinavia」 + 일반 상식
- 생선: 절인 청어, 염장 연어(그라블락스), 훈제 연어, 대구, 새우·생선알
- 고기: 미트볼(셰트뷜라르/프리카델러), 순록·사슴 고기, 양고기 발효·건조육(페로 제도), 간 파테
- 곡물·빵: 호밀빵, 크네케브뢰드(바삭 호밀빵), 귀리·보리 죽
- 유제품: 스키르(이미 6.0 스퀴르로 사용), 산양 치즈(브루노스트), 버터
- 채소·식물: 감자(포포토 대체), 비트, 적양배추, 순무, 딜, 링곤베리·블루베리
- 베이커리·디저트: 시나몬 번, 카다몬 번, 와플, 공주 케이크, 클라드카카
- 음료: 글뢰그, 미드(벌꿀주, 북유럽 신화), 블랙커피, 과일차
- 신화 소재: 미드(시인의 벌꿀주), 이둔의 사과(5.0 픽시사과와 비슷한 소재), 헤이드룬(염소 젖 미드) 등은 이름 짓기 후보.
- 이름 규칙 [확정]: 레시피 이름은 "실제 요리명" 또는 "지명+재료+조리법" 형태. 실제 요리명이 우선 → 북유럽 실제 요리를 후보로 놓고 공개된 레시피와 대조하는 방식이 유효.

### 5. 꾸준히 다시 쓰이는 요리 재료 [확정]
발효 버터(3.0), 크림 치즈·젤라틴·계피·드래곤 고추(2.0), 외눈거인 양파(3.0), 알라미고 소금(4.0), 어둠후추·꼬마레몬·고지대 밀가루·프란토이오 기름·크림버섯·피토마토·노르브란트 박하(5.0), 엘피스 새알·사향소 젖·검은밀가루(6.0)
→ 요리 재료 슬롯 중 과거 확장 재료 비중: 3.0 30%, 4.0 20%, 5.0 33%, 6.0 33%, 7.0 43% (증가 추세). 8.0도 7.0·6.0·5.0 재료가 섞일 가능성이 높음 [패턴].

## B. 연금 (연금술사)

### 1. 구성 [확정]
- 마도서·치유서 5쌍(가죽 5종과 1:1 대응), 약품 3계열(3단계 약 + 5능력 환혹약), 연금재(마법 잉크·환혹수·성장 촉진제 등), 소수의 조경·기타(납품용), 신규 직업 무기(7.0 붓).
- 마법 잉크 = 새 금속 모래/광석 + 생물 부산물 + 물 (7.0 텅스텐 잉크에는 3.0 무지개목화가 들어감).

### 2. 약품 시리즈는 확장마다 이름이 바뀜 [확정]
| 구분 | 3.0 | 4.0 | 5.0 | 6.0 | 7.0 |
|---|---|---|---|---|---|
| 능력 환혹용 완제 | 연금용제 | 탕약 | 환혹약 | 환혹약(5~8등급) | 보석약 |
| 환혹 중간재(연금재) | 연금용제 | 영험수 | 환혹수 | 환혹수 | 보석수 |
| 3단계 약 (장인/거장/명인) | 없음 | 약차 | 물약 | 약주 | 약액 |
| 결속약 | 결속약 | 강력결속약 | 극결속약 | - | - |
- 등급 번호는 x.0=1등급, x.05=2등급, x.2=3등급, x.4=4등급 순. 6.x는 칠흑 번호를 이어서 5~8등급 [확정].
- [패턴] 8.0은 새 이름 + 1등급부터 시작할 것. 6.0만 이름과 등급 번호를 이어 쓴 예외.
- 3단계 약 이름 순서 [확정]: 약차 → 물약 → 약주 → 약액 (모두 "약X" 형태, 한 글자만 바뀜) → [추리] 8.0도 "약?" 형태일 가능성.

### 3. 약품 재료 구성 [확정]
- 3단계 약: 신규 천연수 1~2 + 신규 부산물 1~2 + 허브 2 (+ 칡뿌리 2: 4.0~6.0 3확장 연속 사용, 7.0에서 사라짐).
- 환혹약: 천연수 + 5능력별 허브 2 + 에테르 모래.
- 5능력 허브 5종은 확장마다 새로 나오되, 5.0 허브가 6.0·7.0 환혹수·보석수에 그대로 재사용됨 (뜰냉이·빛거베라·라임바질·긴잎라벤더·참나리).
- 에테르 모래 이름 [확정]: 6.0 "효월의 에테르 모래", 7.0 "황금의 에테르 모래" → [패턴] 8.0 "백은의 에테르 모래"일 가능성(2확장 연속 확장명 사용, 5.0 이전은 "섬광/암흑" 같은 별칭).

### 4. 성장 촉진제 [확정]
그리스 문자 순: 알파~델타(2.0), 입실론·제타(3.0), 에타·세타(4.0), 이오타·카파(5.0), (6.0 없음), 람다(7.0)
→ [패턴] 8.0은 뮤(μ) 또는 뉴(ν)일 가능성. 6.0은 공백이라 규칙이 완벽하지는 않음.

### 5. 마도서·마법 잉크 [확정]
- 마도서 1쌍 = 마법 잉크 + 가죽 + 금속 + 목재(또는 보석). 가죽 5종이 곧 마도서 5쌍이므로 가죽 이름 추리 = 마도서 이름 추리.
- 신규 직업 무기(7.0 붓, 6.0 낫·현학도구, 5.0 건블레이드)는 x.0에서 해당 레벨 전 구간(예: 7.0 붓 82~100)이 한꺼번에 추가됨.

## C. 한계
- 요리 모티브 매핑은 요리 이름 기준의 해석이라 일부 요리는 지역과 무관함.
- 북유럽 후보 목록은 일반 지식과 여행 가이드 기반이며 게임 데이터 근거가 아님.
